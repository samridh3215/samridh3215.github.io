universalMods

Open source, MIT licensed

A local web floor where a master Orchestrator plans work and delegates it to Codex or Claude Code agents. Each agent runs its real CLI in a live terminal, alongside a shared kanban and plan board, inter-agent messaging and a live roadmap drafted by a PM agent as a Mermaid flowchart.

Everything is a mod: views, guards and workflows are hot-reloading folders with a manifest and server and client halves, and a Mod Builder agent can write one from a single sentence. Guards can deny dangerous tool calls, and the server binds to 127.0.0.1 behind a per-run token.

02

GenieTest

Test automation, QE tooling

Cursor alone has no project-specific context, cannot control what it asks the user, and is unreliable on large repositories. GenieTest closes those gaps with a custom MCP server, Cursor rules for prompt engineering, a Cursor extension and a purpose-built RAG dataset, so QE engineers get test automation scripts faster.

The data pipeline chunks the team's test repositories into a test functions database (description, steps, dependencies) and a helper functions database (usage patterns). OpenAI's Batch API did the initial extraction, the output was quality-checked by hand, and embeddings come from a hosted Snowflake Arctic model.

The MCP server exposes the tools: a steps generator breaks the request into structured steps, the user reviews them, a vector search finds the closest existing test, and a code generator then reuses that test, or writes a new test in the same or a new class, pulling helper functions per step. A review and edit tool does the same for changes to an existing test.

GOSniff

Personal project

Captures packets with the network interface in promiscuous mode and streams them to a web interface over WebSocket for real-time inspection.

For each packet it reports the protocol (by OSI layer and port), source and destination IP addresses, and source and destination MAC addresses where applicable. Useful for protocol debugging, security monitoring and teaching how traffic moves.

04

Early Speed Breaker Detection

National hackathon, top 10 of 75 teams

Road accidents from speed breakers and potholes cause around nine deaths a day. Smartphone accelerometer and location data feed a TensorFlow RNN that classifies speed breakers, potholes and normal road. Because no public dataset existed, we built a custom one.

A hazard is only confirmed when several devices agree at the same coordinates, which keeps false positives down. Confirmed locations build a live hazard map, and drivers approaching one get an advance alert.

Result
About 80% classification accuracy; top 10 of 75 teams
Built with
TensorFlow RNN, Django, JavaScript client, geospatial database

Mock Stock Trading

Personal project, built before AI coding tools

NOT vibecoded

I built this before AI coding tools were a thing. Every part of it, front end, back end and data, came from documentation, grinding through Stack Overflow answers and following YouTube tutorials. Most of my full stack knowledge, and my habit of working problems out the slow way first, comes from this project.

Practise trading with virtual currency and no financial risk. Free API keys rarely offer real-time data, so the simulator replays historical market data, with portfolio management and performance tracking.

It was the project where I learned how a whole application fits together: serving data, handling user actions, keeping state and showing it back in a usable interface.
